Welcome to my new Jekyll-powered website! This is a sample post to demonstrate how Jekyll works.

## What is Jekyll?

Jekyll is a static site generator that transforms plain text into beautiful websites and blogs. It's perfect for personal websites, project documentation, and blogs.

## Features

- Simple and fast
- Write content in Markdown
- Version control with Git
- Host for free on GitHub Pages
- Highly customizable

Check out the [Jekyll docs](https://jekyllrb.com/docs/) for more info on how to get the most out of Jekyll.
